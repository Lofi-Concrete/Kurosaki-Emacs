* 心智模型

** 三层结构

| 层   | 是什么                                 | 例子                       |
|------+----------------------------------------+----------------------------|
| 缓冲 | buffer：一个文件 / 一个输出 / 一个界面 | =init.el=、=*compilation*= |
| 窗口 | window：屏幕上显示某个缓冲的一块区域   | 左右分屏的两个窗           |
| 帧   | frame：一个操作系统窗口（GUI 或 TTY）  | =emacs= 开的那一个         |

- 同一个缓冲可以同时显示在多个窗口里；关窗口不杀缓冲，杀缓冲也不一定关窗口。
- 标签栏（=tab-line=）按窗口记“这个窗口最近看过哪些文件”，=C-<tab>= 在标签间切。
- 真实进程只有一个：GUI 实例自己就是 server（见下一节），所以 =C-x C-c= 是退出一切。

** 两种“模式”，别混淆

| 模式      | 含义                                                           |
|-----------+----------------------------------------------------------------|
| 主模式    | 每种语言的规则（=python-ts-mode=、=org-mode=…），一次只有一个 |
| 次模式    | 附加功能（=flymake-mode=、=yas-minor-mode=…），可叠很多个     |
| meow 状态 | 打字还是操作（=insert= / =normal= / =motion=），见下一节       |

** 键位从哪来

- 手写的 keymap：=unzeit/leader-map= 及其子表（=lisp/editor.el=）。
- meow 的 normal / motion / insert 状态表（=lisp/editor.el= 的 =unzeit/meow-setup=）。
- 各包自己的键（magit、org、corfu、vertico…），本手册只列常用的。
- 全局兜底 =C-x= 前缀仍然完全可用：=C-x C-f=、=C-x C-s=、=C-x 4 b= 都没被改掉。

* 启动、连接、退出

** 启动

| 命令                            | 结果                                                           |
|---------------------------------+----------------------------------------------------------------|
| =emacs=                         | 起 GUI 实例；它同时是 server（=server-start= 在 =core.el= 里） |
| =emacs 文件=                    | 直接打开该文件（不显示主屏）                                   |
| =emc=                           | 在当前终端开一个 TTY 帧；没有 server 时自动起 daemon           |
| =emc 文件= / =emc +42 文件=     | 在终端打开文件 / 并跳到第 42 行                                |
| =emacsclient -c=                | 再开一个 GUI 帧（接到已有实例上）                              |
| =emacsclient -e '(kill-emacs)'= | 关掉整个 server（改完配置后重启用）                            |

- =emc= 是 =~/.local/bin/emc=，内容就是 =emacsclient -t -a ""=。
- 启动时没有文件参数 → 显示主屏（dashboard）；有文件 → 直接开文件。
- 启动参数里 =+行号= 这种写法是 emacsclient 的语法，=emacs= 自己用的是 =+行:列 文件=。

** 退出

| 键        | 作用                                       |
|-----------+--------------------------------------------|
| =SPC q=   | 保存所有缓冲并退出（=C-x C-c= 同义）       |
| =C-x 5 0= | 只关当前帧（GUI 实例做 server 时不算退出） |
| =SPC b k= | 只关当前缓冲                               |
| =q=       | meow：关当前窗口；没有别的窗口时关缓冲     |

- 单实例 GUI 下 =SPC q= / =C-x C-c= 都是退出整个 Emacs（不再是只关 client）。
- 退出前会问“是否保存修改过的缓冲”，=y= / =n= / =!= 照提示答。

* meow 模态编辑

** 三个状态

| 状态   | 用途                   | 怎么进去 / 出来                   |
|--------+------------------------+-----------------------------------|
| normal | 移动、选区、删除、命令 | =ESC=（从 insert 回）；启动时默认 |
| insert | 一切字符都是字面输入   | =i= =a= =I= =A=；=ESC= 回 normal  |
| motion | 只用于阅读（j/k 翻动） | meow 在部分只读缓冲自动启用       |

- 光标形状跟状态走：normal / motion 是方块，insert 是细竖线，带选区时临时变细竖线。
- =SPC= 只在 normal / motion 态是 leader；insert 态它就是空格。
- motion 态也能用 leader（配置里把 =SPC= 挂到了 motion 表上）。
- meow 还有一个 keypad 态（把 Emacs 前缀当 leader 用），本配置没有入口键，
  需要时 =M-x meow-keypad=；日常可以不管它。
- 状态显示在模式行最左边（=NORMAL= / =INSERT= / =MOTION=）。

** insert 态

- 除了下面这些，所有键都是字面输入（包括 =SPC=、=TAB= 走全局的缩进命令）。
- =ESC= 回 normal；=C-g= 中断当前命令。
- =C-M-i= 手动触发补全（corfu + capf，见[[*缓冲内补全]]）。
- =C-x= 前缀照常可用：=C-x C-s= 保存、=C-x C-f= 打开文件。
- =M-p= / =M-n= 上移 / 下移当前行（代码与文本缓冲）。

** 数字：一个键，两种含义

| 情况     | =3= 的意思是                                         |
|----------+------------------------------------------------------|
| 没有选区 | 次数前缀：=3j= 下移三行、=3x= 选三行、=-3j= 上移三行 |
| 有选区   | 把选区按当前类型再扩 3 个单位（=0= 表示 10 个）      |

- 原理：数字绑的是 =meow-expand-N=，没有选区时回退成 =digit-argument=（=meow-var.el=
  的 =meow-selection-command-fallback=）。
- =-= 是负前缀，给下一个命令反向：=-n= 反向搜索、=-3j= 上移三行。
- ★ 旧版速查表把 =0..9= 写成“扩展选区到词 / 符号 / 行…”，那是错的（与实际实现不符）。
  以本节为准；=SPC m ?= 里那几行说明待修。

** 文本对象：=,= / =.= 后面跟一个字符

| 字符 | 对象             | 例子（光标在括号里）                 |
|------+------------------+--------------------------------------|
| =r=  | 圆括号 =()=      | =,r= 选括号内，=.r= 连括号一起选     |
| =s=  | 方括号 =[]=      |                                      |
| =c=  | 花括号 ={}=      | 最常用：=,c= 选函数体                |
| =g=  | 字符串引号内     | =,g= 选字符串内容，=.g= 含引号       |
| =e=  | 一个符号         | 适合选变量名 / 函数名                |
| =p=  | 段落             | 以空行分隔                           |
| =l=  | 一行             |                                      |
| =v=  | 视觉行（折行前） |                                      |
| =d=  | 一个 defun       | 选整个函数                           |
| =b=  | 整个缓冲         | =[b= 跳到缓冲开头 =]b= 跳到结尾      |
| =w=  | 一个 window      | Emacs 的 window 对象，少用           |
| =.=  | 一个句子         | 注意：这是对象名“句号”，不是分隔符 |

- =[= 和 =]= 也用同样的字符：=]c= 扩选到花括号块的结尾，=[b= 到缓冲开头。

** 匹配规则

- =orderless=：空格分段、顺序随意、大小写不敏感。=li mo= 能命中 =lisp/modeline.el=。
- 文件补全还叠加 =basic= 与 =partial-completion=：路径仍可按前缀补，=*/= 之类也认。
- 右侧灰色注释由 =marginalia= 提供（文件大小、修改时间、主模式、git 状态）。
- 预览由 =consult= 提供：移动候选停 0.2 秒就预览，=C-g= 取消整次会话。
- 历史（含搜索词、=M-x= 命令、kill ring）由 =savehist= 持久化，重启还在。

** TAB 的语义

全局 =TAB= 绑的是 =unzeit/tab-dwim=（=lisp/completion.el=）。

| 情况             | TAB 干什么             |
|------------------+------------------------|
| 有选区           | 缩进整个选区           |
| 光标处有补全候选 | 补全                   |
| 什么都没发生     | 插入一个制表符         |
| =C-u TAB=        | 强制刚性缩进（不兜底） |

- 网页模板族（=html-mode= / =mhtml-ts-mode= / =web-mode= / =jsp-mode=）里
  TAB 不展开 snippet —— 否则打 =<form= 一按 TAB 就被塞成多域模板。
  snippet 仍可从补全候选里选，或 =M-x yas-insert-snippet=。
- 在 snippet 的活动域里，TAB 是“跳到下一个域”；网页缓冲里则优先补全。

* Java Web / Maven / Tomcat

** 一条命令起一个新项目

=SPC j n= 会问 groupId / artifactId / Java 包名 / 目录 / WAR 名，然后生成：

| 文件                                   | 内容                                                    |
|----------------------------------------+---------------------------------------------------------|
| =pom.xml=                              | war 打包，Servlet 4.0 / JSTL，=maven.compiler.release=8 |

** 开发循环

| 步 | 动作                                                           |
|----+----------------------------------------------------------------|
|  1 | =SPC j s= 准备 context（幂等，第一次必做）                     |
|  2 | =SPC j r= 启动 Tomcat（日志进 =*tomcat*= 缓冲）                |
|  3 | =SPC j b= 打开首页 =http://localhost:8080/<WAR名>/=            |
|  4 | 改 =.java= → =SPC j c=（mvn compile）→ 约 0.35 秒自动 reload |
|  5 | 改 =.jsp= → 存盘即可，刷新浏览器                              |
|  6 | =SPC j t= 跑测试、=SPC j p= 打包 WAR、=SPC j l= 看日志         |
|  7 | =SPC j k= 停止 Tomcat                                          |

** 机制（知道这些能省很多时间）

- 每个项目一份隔离的 =CATALINA_BASE=，放在 =~/.cache/tomcat-base/<项目目录名>=，
  项目树里只有源码，不会被 Tomcat 的运行时文件污染。
- context 描述符是“零拷贝 + 可 reload”：=docBase= 指向 =src/main/webapp=，
  =target/classes= 用 =PreResources= 挂成 =/WEB-INF/classes=，所以改完 Java
  只需要 =mvn compile=，Tomcat 会自动重新加载上下文。
- 依赖 jar 用 =SPC j d=（=mvn dependency:copy-dependencies=）拷进
  =src/main/webapp/WEB-INF/lib/=；这个目录已在 =.gitignore= 里。
- 默认端口 8080 / shutdown 8005；要改改 =langs/servlet.el= 顶部的两个变量。
- 可选：=M-x unzeit/servlet-compile-on-save-mode= 让每次保存 =.java= 自动编译
  （代价是每次存盘跑一次 mvn，默认关）。

** Java 本身

- 主模式 =java-ts-mode=，LSP 是手装的 =jdtls=（=~/.local/opt/jdtls=），
  由 =eglot-java= 接管 Maven 项目的识别、运行、测试。

** 配置

- 后端：DeepSeek 官方 API（OpenAI 兼容），模型 =deepseek-chat= 与 =deepseek-reasoner=。

  #+end_src

- 只在按键时才发请求：没有行内补全、没有后台调用。key 改了用 =SPC a k= 重读。

** 用法

| 键        | 作用                                                                |
|-----------+---------------------------------------------------------------------|
| =SPC a c= | 开对话（gptel）。对话缓冲里 =C-c RET= 发送                          |
| =SPC a r= | 改写选区：给出 diff 预览，逐段接受 / 拒绝                           |
| =SPC a e= | 解释选区（代码或文字），结果写进 =*AI*= 缓冲                        |
| =SPC a t= | 翻译选区（中文→英文，其它→中文）                                  |
| =SPC a A= | 在项目根开 aider（整仓库改代码，需先 =uv tool install aider-chat=） |

- 模型名、host 这类本机覆盖写在 =~/.emacs.d/ai-settings.el=（不随仓库部署）。

** 改配置的标准流程

1. 改仓库里的文件（=SPC c c= 打开源 =init.el=，=SPC c l= 打开 =lisp/= 目录）。
2. 部署：=guix home reconfigure ~/guix/home/home.scm=（或跑 =~/guix/home/reconfigure.sh=）。
3. 重启 Emacs：=emacsclient -e '(kill-emacs)'= 然后重新 =emacs=。
   （GUI 实例本身就是 server，=kill-emacs= 会把它关掉。）

- =~/.emacs.d/= 下是只读的 store 链接，改了不会生效，reconfigure 也会覆盖。
- 本机私有改动写在 =~/.emacs.d/init-local.el=（不部署、不会被覆盖）。
- Customize 写进 =~/.emacs.d/custom-state.el=，也是机器本地的。

** 包管理

- 包装在 =~/.emacs.d/elpa/=，启动用 =package-quickstart= 加速。
- 归档镜像：自动在 4 个国内镜像里测速挑最快的（tuna / ustc / bfsu / nju），
  全挂则回退官方源（走 mihomo 代理）。测速结果缓存 7 天，**启动时零网络请求**。
- =SPC c p= 包列表、=SPC c u= 升级全部——这两个入口才会按需刷新归档。
- 缺的包会在**第一次需要时**自动安装（例如首次打开 =.c3= 文件时装 c3-ts-mode）。
- ★ 升级 Emacs 之后必须重编所有包：=C-u SPC c D=（=package-recompile-all=）。
  旧字节码 + 新 Emacs 的症状千奇百怪（典型：vertico 候选变成一行报错文字）。

** 体检（=SPC c D=）

一次看全七件事：启动耗时、每个命令的固定开销（=post-command-hook=，>1ms 的会标记）、
缺失的 tree-sitter 语法、找不到的 LSP 可执行文件、缺字体、字节码版本不符、
重复安装的包、最近的警告。=C-u SPC c D= 会先重编 elpa 字节码再出报告。

** 加一门语言 / 加一个键

- 新语言：在 =~/.emacs.d/langs/= 下加一个 =<语言>.el=（仓库里是
  =~/guix/home/lang/<工具>/langs/=），用这几行登记即可：
  =unzeit/treesit-source=、=unzeit/remap-mode=、=unzeit/eglot-server=、
  =unzeit/apheleia-mode=、=unzeit/define-on-demand-mode=。
  规矩写在 =~/guix/AGENTS.md= 的 R3 一节。
- 新按键：在 =lisp/editor.el= 里用 =defvar-keymap= 定义，再挂进 =unzeit/leader-map=。
  详细说明见该文件里 =unzeit/leader-descriptions= 附近的注释。

* 排障

| 症状                             | 原因 / 处理                                                                                            |
|----------------------------------+--------------------------------------------------------------------------------------------------------|
| 改了配置没生效                   | store 是只读快照：要 reconfigure 再重启 Emacs                                                          |
| =SPC c c= 打开的文件是只读的     | 部署还没更新（=unzeit/config-directory= 回落到了 =~/.emacs.d=）                                        |
| 打字 / 移动光标卡顿              | 先看电源档：离电 + 省电 EPP 时 CPU 只在 1.5GHz 附近。插电或用性能档对比；再看 =SPC c D= 里 >1ms 的钩子 |
| 补全不弹                         | =C-M-i= 手动触发；仍不弹就 =SPC c D= 看 capf/服务器                                                    |
| LSP 没连（模式行 =LSP= 是灰的）  | 服务器不在 =exec-path= 上，或首次索引还没完（zls/rust-analyzer 可等数十秒）                            |
| 代码有高亮但跳转不准             | C/C++ 缺 =compile_commands.json=；用 CMake 时加 =-DCMAKE_EXPORT_COMPILE_COMMANDS=ON=                   |
| 列表 / 命令突然变成一行报错文字  | elpa 字节码与 Emacs 版本不匹配：=C-u SPC c D=                                                          |
| 打开文件提示 “Break the lock?” | 上次 Emacs 被杀留下的 =.#文件名=，删掉该文件即可                                                       |
| 中文变豆腐块 / 图标是方框        | 字体没装（Maple Mono NF CN / LXGW WenKai Mono）；换字体后要重启                                                   |
| =C-x C-c= 把整个 Emacs 退了      | 单实例设计（GUI 实例即 server）；只关帧用 =C-x 5 0=                                                    |
| 表格越往右越错位                 | 别把 org 表格写得比窗口还宽；=C-c C-c= 重排一次                                                        |
| 网页里 TAB 不展开 snippet        | 故意的（见[[*TAB 的语义]]）                                                                                |
| 弹窗抢焦点 / 关不掉              | =C-'= 收起；=C-g= 取消                                                                                 |
