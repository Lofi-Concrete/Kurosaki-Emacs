* 30 秒：三件事

| 事       | 做法                                                           |
|----------+----------------------------------------------------------------|
| 两种状态 | =insert= 打字；=ESC= 回 =normal= 做操作；=i= / =a= 回到 insert |
| 一个前缀 | =normal= 态按 =SPC= 是命令 leader；insert 态 =SPC= 就是空格    |
| 万能救命 | =C-g= 取消；=u= 撤销；=C-M-_= 重做                             |

- 按下 =SPC= 后停 0.3 秒，屏幕下方会列出这一组还剩哪些键（which-key 提示）。
- 记不住键时：=SPC m ?= 打开“按当前真实绑定生成”的速查表，永远不会过期。
- =SPC m t= 是 meow 自带的交互式教程，练习移动和选区最快。

* 先背这 12 个键（覆盖八成的日常）

| 键        | 作用                            | 什么时候用     |
|-----------+---------------------------------+----------------|
| =j= =k=   | 下 / 上一行                     | 移动           |
| =h= =l=   | 左 / 右一个字符                 | 微调           |
| =e= / =b= | 词尾 / 词首                     | 跨词移动       |
| =w=       | 选中一个词（再按 =w= 多加一个） | 选中即改       |
| =x=       | 选中整行（再按往下多选一行）    | 删行 / 复制行  |
| =i= / =a= | 光标前 / 选区末尾插入           | 开始打字       |
| =d=       | 删除选区（不占剪贴板）          | 删掉选中的东西 |
| =s= / =y= | 剪切 / 复制选区                 | 搬代码         |
| =p=       | 粘贴（有选区则替换）            | 粘贴           |
| =u=       | 撤销                            | 手滑           |
| =v=       | 输入关键词搜索并选中            | 跳到某个名字   |
| =SPC=     | 命令 leader                     | 其余一切       |

* 移动

| 键              | 作用                                                |
|-----------------+-----------------------------------------------------|
| =j= =k= =h= =l= | 下 / 上 / 左 / 右                                   |
| =e= =b=         | 下一个词尾 / 上一个词首                             |
| =E= =B=         | 下一个符号尾 / 符号首（符号 = 连字符那串：foo_bar） |
| =f= 字符        | 本行向后找到该字符并停在上面                        |
| =t= 字符        | 同上，但停在它前一位                                |
| =Q=             | 跳到指定行，并选中该行                              |
| =C-s=           | 当前文件内搜索行（consult-line，边打边预览）        |
| =C-c j=         | avy：候选位置标字母，按字母直接跳过去               |
| =M-g g=         | 跳到第 N 行（不选中）                               |
| =SPC ,=         | 在最近用过的两个缓冲之间来回切                      |
| =C-<tab>=       | 切到右边那个标签（VSC 的 Ctrl+Tab）                 |

* 选中：先选后改（meow 的核心）

| 键              | 作用                                                                                        |
|-----------------+---------------------------------------------------------------------------------------------|
| =w= / =W=       | 选词 / 选符号                                                                               |
| =x=             | 选本行（再按 =x= 往下多选一行）                                                             |
| =H= =J= =K= =L= | 向四个方向扩选                                                                              |
| =o= / =O=       | 选光标所在的括号块 / 往外面再扩一层                                                         |
| =,= 字符        | 选“内部”：=,r= 圆括号内 =,s= 方括号内 =,c= 花括号内 =,g= 引号内 =,p= 段 =,l= 行 =,d= 函数 |
| =.= 字符        | 选“含边界”：同上，但把括号 / 引号一起选上                                                 |
| =[= / =]=       | 扩选到该对象的开头 / 结尾                                                                   |
| =数字=          | 有选区时：把选区再扩 N 个单位（=0= 表示 10 个）                                             |
| =;=             | 光标与选区端点互换（往反方向扩选）                                                          |
| =g=             | 取消选区                                                                                    |
| =z=             | 退回上一次扩选                                                                              |

- 没有选区时，数字是“次数前缀”：=3j= 下移三行、=2w= 选两个词、=-3j= 上移三行。
- 有选区时直接打字 = 用新内容替换选区；=c= = 删掉选区并进入 insert。

* 改

| 键            | 作用                                     |
|---------------+------------------------------------------|
| =d=           | 删除选区（不进剪贴板）                   |
| =s=           | 剪切选区                                 |
| =y=           | 复制选区                                 |
| =p=           | 粘贴（有选区就替换）                     |
| =c=           | 删除选区并进入 insert                    |
| =r=           | 用剪贴板内容替换选区                     |
| =u= / =U=     | 撤销 / 只撤销选区内                      |
| =C-M-_=       | 重做                                     |
| =SPC ;=       | 注释 / 取消注释本行或选区                |
| =m=           | 与上一行合并（选中的是两行之间的缩进）   |
| =M-p= / =M-n= | 当前行上移 / 下移（代码和文本缓冲）      |
| =TAB=         | 缩进；有选区就缩进整块；实在没用才插 Tab |

* 输入与补全

| 键              | 作用                             |
|-----------------+----------------------------------|
| =i= / =a=       | 光标前插入 / 在选区末尾追加      |
| =I= / =A=       | 在上方 / 下方开新行并进入 insert |
| =ESC=           | 回 normal                        |
| =C-M-i=         | 手动触发补全（自动的没弹时）     |
| =TAB= / =S-TAB= | 补全弹窗里下一个 / 上一个候选    |
| =C-j= / =C-k=   | 同上（右手不用离开主键区）       |
| =RET=           | 确认选中的候选                   |
| =ESC=（弹窗里） | 关掉这一次补全                   |

- 补全默认自动弹：输入 1 个字符、约 0.1 秒后出现。来源是 LSP、同语言缓冲里的词、文件名。
- 候选项右边那行小字是文档（corfu-popupinfo），停 0.4 秒才出现。

* C-c：不依赖 meow 状态的快捷入口

| 键        | 作用    | 键        | 作用         |
|-----------+---------+-----------+--------------|
| =C-c t=   | 文件树  | =C-c d=   | 全窗 dirvish |
| =C-c h=   | 主屏    | =C-c D=   | 体检         |
| =C-c e=   | 配置    | =C-c m=   | 完整手册     |
| =C-c s=   | eshell  | =C-c S=   | eat 终端     |
| =C-c R=   | 跑测试  | =C-c J=   | Java/Tomcat  |
| =C-c g=   | Guix 菜单 | =C-c x=   | 终端编译     |
| =C-c A c= | AI 对话 | =C-c A r= | AI 改写      |

- =M-o= 按字母选窗口（需要至少两个窗口）；=C-x o= 是原生循环切窗口。
- 按 =C-c= 停 0.3 秒，which-key 会先列这些自定义键，模式自己的键排在后面。

* 一次完整的开发循环

| 步 | 动作                                        |
|----+---------------------------------------------|
|  1 | =SPC p p= 选项目（或 =SPC f f= 直接开文件） |
|  2 | =SPC p f= 找文件；=SPC f r= 找刚编辑过的    |
|  3 | 改：=i= / =a= 进 insert，=ESC= 回 normal    |
|  4 | =C-s= 搜本文件；=SPC p s= 搜整个项目        |
|  5 | =SPC c C= 编译 / =F9= / =C-x c=             |
|  6 | =SPC c n= 跳到报错行，改完 =SPC c r= 重跑   |
|  7 | =SPC g s= 看 diff；=s= 暂存、=c c= 提交     |
|  8 | =C-x C-s= 保存；=SPC q= 保存并退出          |

* 七天练习（每天 5 分钟，练完就能不看表）

| 天 | 练什么                                                              |
|----+---------------------------------------------------------------------|
|  1 | =h j k l= + =e b= + =w= + =i a= + =ESC=：只用这些改一段注释         |
|  2 | =x d s y p u= + 数字前缀：=3j=、=2w=、=2x=                          |
|  3 | =v= 搜索 + =n= 继续 + =f/t= + =Q= + =C-s=                           |
|  4 | leader 文件/项目/缓冲：=SPC f f/r=、=SPC p p/f=、=SPC b b=、=SPC ,= |
|  5 | 窗口与标签：=SPC w s/v/h/j/k/l/m/u=、=C-<tab>=                      |
|  6 | 开发闭环：=SPC c C= → =SPC c n= → =SPC g s= → 提交               |
|  7 | 文本对象与抓取：=,r= / =,c= / =.d=、=o= / =O=、=G= / =R=            |

* 卡住了怎么办

| 症状                       | 按什么                                              |
|----------------------------+-----------------------------------------------------|
| 弹窗 / 命令不理我          | =C-g=（连按两次往往就干净了）                       |
| 不知道现在能按什么         | =SPC= 停一下看提示；=SPC m ?= 看全表                |
| 光标在别的窗口，打字没反应 | =SPC w h/j/k/l= 或 =SPC w o= 换过去                 |
| 补全没弹                   | =C-M-i= 手动触发；还不行看完整手册“排障”一节      |
| 文件打不开 / 提示锁文件    | 通常是上次 Emacs 被杀留下的 =.#文件名= 锁，删掉即可 |
| 想看某个键绑了什么         | =C-h k= 然后按那个键                                |
| 想看某个命令的名字         | =C-h f= 输入命令名                                  |
